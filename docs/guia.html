Guía de uso

Todo lo necesario para empezar a usar Juord

Desde la instalación hasta la configuración de la IA, Zotero y la exportación de tus documentos. Si es la primera vez que lo usas, sigue las secciones en orden.

Instalación en Windows

Descarga el instalador o la versión portable desde la sección de descargas. Ambas pesan lo mismo en funciones: la diferencia es solo cómo se ejecutan. Los nombres de los archivos todavía incluyen «Editor Inteligente IA», el nombre técnico anterior del proyecto; el producto ya se llama Juord.

Con el instalador

Ejecuta Editor-Inteligente-IA-Setup.exe. Es un instalador Squirrel por usuario: muestra brevemente su ventana de instalación, crea accesos directos y guarda la aplicación en: 

%LOCALAPPDATA%\EditorInteligenteIA\app-<versión>\EditorInteligenteIA.exe

No es necesario conservar abierto el instalador para utilizar el programa.

Con la versión portable

Descarga Editor-Inteligente-IA-Portable-0.8.3.exe y ejecútalo directamente, sin instalación. Puedes moverlo a un USB o a cualquier carpeta; la configuración se guarda junto al ejecutable.

Como la aplicación aún no está firmada digitalmente, Windows SmartScreen puede mostrar un aviso de «Editor desconocido» la primera vez. Pulsa Más información → Ejecutar de todas formas.

Modo Rápido

Pensado para quien no quiere configurar parámetros y quiere un borrador ya:

  1. Adjunta los materiales o describe el documento que necesitas.
  2. Pulsa Crear documento con IA.
  3. Edita el resultado directamente en el documento o conversa con el asistente para cambiar fragmentos.

Este modo usa el modelo elegido en Ajustes (Gemini o el enrutador gratuito de OpenRouter) y mantiene la longitud automática según los materiales y el conocimiento del modelo.

Modo Profesional

Conserva el mismo enunciado y los mismos archivos que el Modo Rápido, pero permite controlar:

  • Gemini 3.1 Pro/Flash/Flash-Lite, openrouter/free o un modelo :free específico.
  • Nivel de razonamiento, temperatura y Top-P cuando el modelo los admite.
  • Longitud, una o dos pasadas, política de fuentes y filtros del modelo.
  • Instrucciones maestras, función de cada adjunto y análisis editable de los requisitos.
  • Perfiles reutilizables para informes profesionales, documentos estructurados y trabajos basados únicamente en los materiales.

La aplicación analiza automáticamente las instrucciones con Flash-Lite, detecta el tipo de documento, los apartados y los requisitos, y usa esa lectura estructurada al redactar. La búsqueda web solo se activa cuando se solicita explícitamente.

Configurar la IA

No hay que editar archivos ni usar la terminal:

  1. Abre Ajustes. Si todavía no hay clave, la aplicación lo abre automáticamente.
  2. Elige Gemini o OpenRouter gratis.
  3. Crea una API Key en Google AI Studio u OpenRouter y pégala.
  4. Pulsa Guardar y comprobar.

Con OpenRouter, la opción predeterminada es openrouter/free: la app consulta el catálogo y elige un modelo instructivo gratuito, popular y compatible, evitando clasificadores de seguridad y modelos que no sirven para conversar o editar documentos. También se admite un modelo gratuito específico terminado en :free. Cualquier identificador de pago se sustituye automáticamente por openrouter/free para evitar cargos accidentales.

La aplicación prueba la conexión antes de activarla. Las claves se guardan en el perfil local de la aplicación y nunca dentro de los documentos. Los modelos gratuitos tienen límites diarios y su disponibilidad puede variar según el proveedor.

Conectar Zotero

Abre Referencias → Fuentes y Zotero:

  1. Para trabajar en local, abre Zotero Desktop y pulsa Detectar Zotero Desktop. Si Zotero lo solicita, activa en Ajustes → Avanzado la opción que permite la comunicación con otras aplicaciones.
  2. Para Zotero.org, pulsa Crear API Key en Zotero, pega la clave y pulsa Guardar y conectar.
  3. Elige biblioteca y colección, busca, selecciona e importa.
  4. Usa Sincronizar cambios desde la última versión para actualizar lo ya importado.

La lectura local no modifica Zotero Desktop. La fusión remota solo se ejecuta tras una confirmación explícita y necesita permiso de escritura en la API Key.

Edición y revisión después del borrador

  • Chat contextual sobre el documento y los materiales adjuntos.
  • Previsualización antes de aplicar una reescritura, con edición directa opcional.
  • Acciones específicas para reforzar argumentos, aclarar ideas, verificar afirmaciones y comprobar el cumplimiento de requisitos.
  • Comentarios, respuestas y control de cambios como en Word.
  • Comparación estructural entre versiones, DOCX, PDF, HTML, Markdown o texto, con adopción opcional de la versión comparada.

Exportar e importar

Juord lee y escribe DOCX, PDF y ODT conservando estilos, notas al pie y finales, campos nativos (tablas de contenido, referencias cruzadas, rótulos), ecuaciones como OMML editable, tablas con fórmulas y objetos flotantes como imágenes y cuadros de texto.

El instalador y el portable incluyen todo lo necesario: no hace falta Word ni LibreOffice instalados para exportar.

Límites conocidos

  • La comparación permite revisar el cambio unificado y adoptar la versión completa; todavía no combina selectivamente cada revisión.
  • El asistente local de estilo aplica reglas prácticas de español; no sustituye un motor lingüístico completo.

Preguntas frecuentes

¿Puedo usarlo sin API key?

Sí. El editor, la maquetación y la exportación DOCX/PDF/ODT funcionan sin conexión. Solo necesitas una API key para el asistente de IA.

¿Dónde se guardan mis documentos?

En tu equipo, donde tú decidas guardarlos. La aplicación no sube tus documentos a ningún servidor propio.

¿Qué pasa si el modelo gratuito de OpenRouter no está disponible?

Puedes elegir otro modelo :free del catálogo desde Ajustes, o cambiar a Gemini con tu propia API key.

¿Cómo reporto un error o pido una función nueva?

Abre un issue en el repositorio de GitHub.
